# 1e308

Notes, resources and tips for anyone who makes or plays incremental games.

**Live site:** https://bonzerkitten.github.io/1e308/

Built with [Starlight](https://starlight.astro.build) and published to GitHub Pages on every push to `main`.

## Working on the site

| Command           | Action                                          |
| :---------------- | :---------------------------------------------- |
| `npm install`     | Install dependencies                            |
| `npm run dev`     | Start a local preview at `localhost:4321/1e308` |
| `npm run build`   | Build the site into `./dist/`                   |
| `npm run preview` | Preview the built site locally                  |

Pages live in `src/content/docs/`, one Markdown file per page. The sidebar is configured in `astro.config.mjs`.
